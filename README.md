## 接缝过渡 5 条复核意见修复

1. **去闪不再反向破坏前 N 帧**：去闪基于“已做接缝增益后的 out”计算，且**只作用于第 n 帧之后**；前 N 帧只受接缝增益影响（首帧在限幅内严格对齐上一段末帧）。
2. **增益限幅收紧**：整体亮度增益 0.8–1.25；通道相对偏差 ≤5%（色度比亮度更保守），避免强行三通道对齐造成明显色偏。
3. **目标取最后 5 帧中位数**：上一段末帧偶发闪烁脉冲不会把过渡目标带偏。
4. **去闪自适应 + 低默认**：只修正偏离平滑曲线超过 0.03（≈7.6/255）的高频帧，窗口限第 n 帧后 48 帧；默认强度重锚定 0.25、续接 0。真实缓慢灯光变化不会被压掉。

- **父版本兜底不再选未来版本**：`_pick_parent_version` 只在“目标版本生成之前存在”的候选里选；没有更早候选、或时间戳缺失且候选不唯一时，明确报“无法确定父版本，请先恢复该轮重跑前一段”，不再自动采用目标生成之后的版本。

## 回抽旧轮与存盘提升修复

- **存盘/提升 4 个缺陷修复**：补存盘段号 0 误判（`relay_stage_index or -1` 把 0 当成 -1，首段存盘后补提升失效）；提升不再用“大小 + 秒级 mtime”去重（同大小同秒的不同 latent 会静默沿用旧版）；迟到/未选中的旧版本存盘不再覆盖当前选用版本的稳定 latent；抽卡/通过/选用时若稳定 latent 提升失败会**阻止推进并提示**，不再静默带着旧父 latent 继续。
- **回抽旧轮（B 方案）**：清空重置 / 新建一组都会把当前轮归档为历史组并进入下一轮；默认**保留最近 10 轮可回抽**。任意历史轮卡片可点「本段抽卡」：锚点锁定该轮的分段结构 / 源素材范围 / 父 latent 链；提示词、参考、采样参数等使用**当前编辑**（本轮设置仍然生效）。
- 回抽旧轮使用该轮自己的潜桥链；旧数据组共用目录或缺少父 stage 时，从该组唯一存盘目录恢复父 latent 到独立链，失败明确报“哪一段 latent 缺失”，不猜不凑；结构锚点不匹配时直接拦截并提示先恢复该轮。
- 回抽旧轮后，该轮后续段只加“待更新”提示（不失效、不阻断合并）；用户愿意替换再自行重跑。
- 超过最近 10 轮的轮次仍可预览/合并，但不再允许回抽。

## 潜桥裁头全量修复

- **修复裁头完全没生效（核心）**：分段节点输出的 `context` 现在携带 `relay_trim_frames / relay_context_frames / relay_pre_roll_frames`。此前内部裁头读不到该键，实际执行“裁 0 帧 → 不裁”，导致每段开头残留 C 帧（22 帧约 0.9 秒）预卷/上一段延续内容、结尾被 normalize 截掉；生成音频也一起失效。
- 裁头节点在 `relay_run_id` 存在但缺裁头键时**显式报错**，不再静默按 0 帧处理。
- 潜桥开启后按最终生成帧数 `G=L+C` **重新校验单段上限**；超限在排队阶段直接报可读错误（不再静默生成 396 帧）。
- 每段独立潜桥链：新建一组 / 清空重置会生成新的稳定 `relay_run_id`，历史组恢复取回本组自己的链；不再出现“恢复旧组却读到新组 latent”。
- 稳定 stage 提升改为**原子替换 + 幂等跳过**；提升失败打印明确原因。存盘节点完成后再做一次提升检查，登记/存盘谁先谁后都能正确接续；下一段开始前校验父段 stage 存在，缺失给出可操作错误。
- 注入改为按“分段节点 → AD-分段预览 → CreateVideo → 采样器”的**连通组件**定位，支持分块解码与多分段；多链不再接错，结构不支持时**阻断排队并提示**，不再静默无桥运行。旧外部桥迁移保留第 4 路 conditioning 连线。
- 潜桥自动重排增加连续性校验：仅处理同一源、时间线连续、源范围连续、从 0 开始的片段；有空隙/跳源时保留用户编辑并提示。重排前后预检单段上限。
- 生成音频识别允许中间夹音频后处理节点；裁头调用关闭无用的 PCM 边车并收敛上游日志（避免每段 1–2MB 无主文件与 emoji 日志在重定向 stdout 下报编码错误）。
- 内嵌运行时裁剪：移除上游实验子包（TIHA/VA，约 200KB）与其单测/.gitignore，包体更小、加载更快。

# AD-分段循环 · ComfyUI-AD-Segmented-Loop

用于 ComfyUI 的素材时间线与分段循环插件，串起素材准备、逐段生成、预览对比与结果保存。

## 三个核心节点

1. **AD-素材准备**：图片、视频、音频批量导入；多轨时间线拖动、裁剪、切断、拼接与合并；支持按小节、每拍、镜头或气口智能切分。
2. **AD-分段生成**：按素材时长组织分段，24 FPS 严格锁帧，适配 H3 的 17k+5 生成帧数；逐段控制宽高、提示词与参考素材。
3. **AD-分段预览**：逐段播放、A/B 对比、指定段抽卡、停止续跑、连续分段循环与片段合并。

搭配 **AD-最终保存**，可将外部处理后的成果批量保存、自动归档与再次合并。

先在分段预览中选择成果，再点击最终保存的「加工所选」；停止后可点击「继续剩余」。普通整图运行会跳过最终保存节点。

## 主要功能

- **多素材导入**：统一管理图片、视频、音频，支持批量加载与拖放导入。
- **剪映式多轨编辑**：视频、音频各 3 轨；支持多选整体移动、同类换轨、独立首尾裁剪、切断、合并与撤销/重做。
- **灵活分段**：按时长、段数或智能切点组织片段；无素材时可按正向提示词中行首 `#` 自动建立分段。
- **智能切分辅助**：音频踩节拍、小节切分、视频镜头检测与人声气口检测。
- **多音源处理**：多路音频独立裁剪、切分与静音，短段按需要补静音。
- **参考素材独立输出**：参考图片、参考视频帧、视频音轨与音频轨素材按端口输出，可按段配置。
- **原始素材直出**：源视频、源音频与分段参考输出分开使用，便于连接现有工作流。
- **清晰预览与对比**：图片、视频、音频分类预览，支持缩放、全屏与 A/B 对比；视频 A/B 为叠加重合擦除（分界线跟随鼠标），图片 A/B 为独立左右/叠加滑杆。
- **自由抽卡与续跑**：指定段重新生成，保留历史成果；支持停止待命、断点续跑与连续分段循环。
- **逐段采用最新设置**：下一次提交读取当前素材、连线与生成设置，已完成成果保留。
- **独立任务与历史组**：工作流任务隔离，可新建独立组并在记录完整时恢复历史组续跑。
- **批量保存与循环复用**：素材与结果可继续作为输入，配合最终保存节点完成批量输出和合并。
- **接缝处理与进度管理**：提供接缝治理、进度保存、素材占用提示及缓存清理；素材占用默认上限 30 GB，可用环境变量 AIDEN_H3_MEDIA_LIMIT_GB 调整。

## 安装与使用

1. 从[最新发布页](https://github.com/tibidefengzi/ComfyUI-AD-Segmented-Loop/releases/latest)下载插件 ZIP，将其中的 `AD-Segmented-Loop` 文件夹放入 `ComfyUI/custom_nodes`，保持只有一份启用的插件。
2. 用运行 ComfyUI 的 Python 安装依赖：
   ```bash
   python -m pip install -r custom_nodes/AD-Segmented-Loop/requirements.txt
   ```
3. 保存工作流、等待当前任务结束后重启 ComfyUI，再按 `Ctrl+F5` 刷新页面。节点位于 **AD-Segmented-Loop** 分类。

H3 的模型、条件编码、采样器与生成链路在外部工作流中连接；模型及第三方二进制不包含在安装包中。

## 潜桥续接（内置，无需外部插件）

- **AD-分段生成**只有一个参数：「潜桥续接」`0 / 5 / 22 / 39`。0=关闭；5/22/39=开启并选择上下文帧数 C。
- 画布不出现桥接、存盘、裁头节点；提交时自动注入。旧工作流里的外部 `H3RelayCopyBridge` / `H3RelayLatentSave` / `H3RelayTrimAV` 会在加载时自动移除并保留连线/参数/进度。
- 输出公式：每段输出 L=17n；H3 生成 G=L+C（自动 5+17k）；内部裁头 C。源/参考视频有帧时窗口自动前置 C 帧；无视频帧时只做 latent 桥接。
- 例：源段 124→119（4.958s），73→68，68→68。全部潜桥时总时长按每段向下取整，5.000s 整做不到；需要严格原时长请选 0。
- 镜头切换不自动检测，切点由用户自行决定。
- 内嵌 ComfyUI-H3-Latent-Relay 0.6.39（MIT）最小运行时；许可见 `h3_loop/_relay_vendor/` 与根目录 `THIRD_PARTY_LICENSES.md`。
