# AD-分段循环 · ComfyUI-AD-Segmented-Loop

用于 ComfyUI 的素材时间线与分段循环插件：把素材准备、逐段生成、预览对比与结果保存串成一条工作流，适合长视频分段生成、潜桥续接与镜头级重做。

## 四个核心节点

1. **AD-素材准备**：图片、视频、音频批量导入与拖放；视频/音频各 3 轨时间线，支持拖动、裁剪、切断、拼接、合并、多选整体移动与撤销/重做；支持按小节、每拍、镜头或气口智能切分；按段输出参考图、参考视频帧、参考视频音频、参考音频、源视频/源音频、起始帧与遮罩专用画面。
2. **AD-分段生成**：按素材时长或段数组织分段，严格 24 FPS 锁帧并适配 H3 的 17k+5 生成帧数；逐段控制宽高、提示词、参考素材与参考范围；内置潜桥续接（含重锚定、接缝曝光过渡、画质校正）。
3. **AD-分段预览**：逐段播放、A/B 对比、指定段抽卡、停止待命与断点续跑、连续分段循环、片段合并、历史轮组查看与循环播放；接入本段成片后继续审批下一段。
4. **AD-最终保存**：把外部处理后的成果批量「加工所选 / 继续剩余」，自动归档、合并片段、源/成品 A/B 对比、高画质预览与母版下载；支持母版画质（近无损 4:4:4 CRF14 等）。

普通整图运行会跳过「AD-最终保存」节点；在预览节点选择成果后再点最终保存的「加工所选」才会加工。

## 典型连线

```
AD-素材准备 ──参考素材/分段清单──▶ AD-分段生成（外部：H3 条件/采样/解码）
        │                                    │
        └──预览媒体/上下文──▶ AD-分段预览 ◀──┘
                                   │
                                   └──成果──▶ AD-最终保存
```

- 分段节点的 `context` 接预览节点，预览节点的 `media` 接本段 `CreateVideo` 输出；
- 素材准备的参考图/参考视频/参考视频音频/参考音频口接 H3 对应参考输入；遮罩专用口可接 SAM/VAEEncode 做局部重绘；
- H3 的模型、条件编码、采样器与解码在外部工作流连接，安装包不含模型。

## 主要功能

- **多素材导入**：图片、视频、音频统一管理，支持批量加载与拖放导入；H3 单次参考输出仍为图片 10、视频 3、音频 3。
- **剪映式时间线**：视频/音频各 3 轨；多选移动、同类换轨、独立首尾裁剪、切断、合并、撤销/重做；拖边与裁剪不触发转码；播放头按 24 FPS 定位。
- **灵活分段**：按每段长度、分段数或智能切点组织片段；无素材时按正向提示词行首 `#` 自动建立分段；无 `#` 按 1 段。
- **智能切分辅助**：音频踩节拍（小节）、视频镜头检测、人声气口检测，结果作为黄色候选切点。
- **多音源处理**：多路音频独立裁剪、切分与静音，短段补齐静音；视频轨静音不影响画面。
- **参考素材按段输出**：参考图片按加载顺序固定端口（参考图1、参考图2…），作用域支持全局参考、本段参考、禁止输出；参考视频/参考音频按轨道位置固定端口。
- **原始素材直出**：源视频、源音频输出所关联的原文件（保留原帧率/尺寸/采样率），与生成规范化输出分开。
- **逐段采用最新设置**：下一次提交读取当前素材、连线与生成设置；已完成成果保留，参数变化不强制整轮重跑。
- **潜桥续接（内置）**：「生成方式」选「潜桥续接」，上下文帧数 C 在「高级设置」里选 `5 / 22 / 39`（推荐 22）；开启后需点「应用分段」按 17n 重排；每段输出 17n、H3 生成 +C、内部裁头 C；第 1 段只 +5。
- **重锚定与接缝治理**：重锚定 0/2/3/5/7/10 段；可开启「重锚定锚定」把上一段成片尾 5/22/39 帧作为 guide 锚定到本段预卷开头（不参与去噪），压掉重锚定冷启动的接缝跳变；接缝曝光过渡（前 12/24 帧每通道增益对齐、重锚定后整段轻量去闪）；桥接模式可选像素质量复位；参考首帧色彩匹配、外观锚、整段校正、质感还原。
- **自由抽卡与续跑**：任意已生成段可重新抽卡并保留历史版本；支持停止待命、断点续跑、连续分段循环与「开始」继续。
- **预览与对比**：图片/视频/音频分类预览；视频 A/B 为叠加重合擦除，图片 A/B 为左右/叠加滑杆；支持缩放、全屏、循环播放。
- **历史轮组**：分段生成历史保留最近 10 轮、每轮最多 200 条；分段缩略图记录「原段号-第几次」，当前轮/历史轮可查看与恢复（历史恢复会先归档当前进度）。
- **批量保存与母版**：最终保存节点支持多成果批量加工、继续剩余、合并片段、下载母版；母版画质可选近无损 4:4:4 CRF14 / 4:2:0 CRF19 等。
- **安全与缓存**：素材占用提示与导入拦截（默认上限 30 GB，可用 `AIDEN_H3_MEDIA_LIMIT_GB` 调整）；清理缓存只删可重建缓存，不动导入源文件、分段结果、成片与进度；运行中不清理。

## 使用流程

1. 在 **AD-素材准备** 导入图片/视频/音频，按需在时间线上裁剪、切分、拼接或智能切分；
2. 设置「每段长度」「分段数」，点 **应用分段** 生成/重排分段；开启潜桥时先选潜桥档位，再点应用分段按 17n 重排；
3. 连接 H3 生成链与预览节点，点预览节点的 **开始** 逐段生成；生成结果可逐段播放、A/B、抽卡、停止后继续；
4. 在预览节点选择/通过成果后，点 **AD-最终保存** 的「加工所选」批量输出；需要多段合并时用「合并片段」或在预览中 Ctrl 多选后合并。

## 安装与使用

1. 从[最新发布页](https://github.com/tibidefengzi/ComfyUI-AD-Segmented-Loop/releases/latest)下载插件 ZIP，将其中 `AD-Segmented-Loop` 文件夹放入 `ComfyUI/custom_nodes/`，保持只有一份启用的插件。
2. 用运行 ComfyUI 的 Python 安装依赖：

   ```bash
   python -m pip install -r custom_nodes/AD-Segmented-Loop/requirements.txt
   ```

3. 保存工作流、等待当前任务结束后重启 ComfyUI，再按 `Ctrl+F5` 刷新页面。节点位于 **AD-Segmented-Loop** 分类。

要求 ComfyUI 支持 `comfy_api` V3 视频接口：**v0.3.48+**（本插件实测 0.43.0）。H3 模型、条件编码、采样器、VAE 与解码在外部工作流中连接，模型与第三方二进制不包含在安装包内。

## 潜桥续接（内置，无需外部插件）

- **AD-分段生成**用「生成方式」二选一：`逐段生成` / `潜桥续接`。开潜桥后在同节点的「高级设置」里设上下文帧数 C（`5 / 22 / 39`，推荐 22）、重锚定周期与沉降锐化；其余锚定项（外观锚、整段校正、质感还原、桥接模式、重锚定锚定）保存在节点 properties 里。
- 切换开关只改参数并提示；**只有点「应用分段」才会按 17n 重排时间线**。潜桥开启但未重排时，点开始生成会被拦下并提示先应用分段。
- 画布不出现桥接、存盘、裁头节点；提交时自动注入。旧工作流里的外部 `H3RelayCopyBridge` / `H3RelayLatentSave` / `H3RelayTrimAV` 会在加载时自动移除并保留连线/参数/进度。
- 输出公式：每段输出 L=17n；H3 生成 G=L+C（自动 5+17k）；内部裁头 C。源/参考视频有帧时窗口自动前置 C 帧；无视频帧时只做 latent 桥接。
- 例：源段 124→119（4.958s），73→68，68→68。全部潜桥时总时长按每段向下取整，5.000s 整做不到；需要严格原时长请用「逐段生成」。
- 若开启潜桥后应用分段提示帧数不足：每段至少 17 帧（C 另需余量），减少分段数或加长素材。
- 内嵌 ComfyUI-H3-Latent-Relay 0.6.39（MIT）最小运行时；许可见 `h3_loop/_relay_vendor/` 与根目录 `THIRD_PARTY_LICENSES.md`。
