# AD-分段循环 · ComfyUI-AD-Segmented-Loop

用于 ComfyUI 的素材时间线与分段循环插件，串起素材准备、逐段生成、预览对比与结果保存。

## v0.5.17

- **最终保存母版画质下拉**：默认 `4:4:4 / CRF14`（约 21MB/5 秒，近无损、保留色度）；可选 CRF12/CRF16/4:2:0 CRF19；不提供 CRF0。VideoFromFile 原样复制。
- **下载母版**：AD-最终保存新增「下载母版」，只保存 `最终_*.mp4` / `final_*.mp4`；播放器禁止原生下载，避免把 `preview_*.mp4` 预览代理当成成片。
- **A/B 交互**：点击对比画面播放、再点停止；到两路较短时长后一起回到 0 一直循环。
- **移除原画细节**：上一版的静帧 1:1 对比已删除。
- **提示词直连修复**：分段节点「正向提示词」直接连 CLIPTextEncode 文本输入时，端口整理不再自动断线。
- **高画质预览**：开启后主预览/A-B 使用原分辨率、原帧率、yuv420p、CRF18 代理；代理只用于播放，不写入保存文件。

## v0.5.18

- **图片分类拆成「图片A / 图片B」两排**：按媒体A/媒体B输入的 role 分组，不再混在一个平铺列表里；仍可用工具栏「A/B」按钮手动选两张对比。
- **音频分类拆成「音频A / 音频B」两排**：同样按 role 分组，方便分别试听、抽卡和对比。
- 视频分类保持「分段生成A / 分段生成B / 合并生成」三排。
- 纯前端改动：保存工作流后 Ctrl+F5 即可。

## v0.5.19

- **彻底重置**：预览节点「清空重置」改为「彻底重置」，点击先显示统计（历史组/生成版本/预览卡/会话与潜桥文件、预计释放空间），二次确认后永久删除当前工作流的生成数据；素材、分段、提示词、参考图、节点参数、input 源素材与导出成品保留，其它工作流不受影响。重置后回到第 1 段、编号从 1 开始。
- **移除「只保存B」**：保存栏不再提供该勾选，A/B 两端都按自己的角色记录与归档；旧工作流的 only_b 字段载入时自动丢弃。
- **参考口连线固定**：素材/轨道增删只重建参考口列表，已连好的参考线按端口名保持原端口，不再被重建或类型修复迁移到别的参考口。
- 本版含后台改动（新增清理模块与接口）：保存工作流并重启 ComfyUI，再 Ctrl+F5。

## 最新版本 v0.5.20

- **普通生成只跑到「AD-分段预览」**：`AD-最终保存` 不再是输出节点；点「开始 / 分段循环」（图片、音频、视频）时，ComfyUI 会直接裁剪最终保存及其后面的处理链，不执行、不校验、不进队列。
- **点「加工所选 / 继续剩余」才运行最终保存**：加工子图追加隐藏输出节点 `AD_FinalSink` 强制执行；加工子图的预览源改用独立内部 id，画布不会再高亮「AD-分段预览」。
- **母版画质旧工作流兼容**：旧工作流「母版画质」为空时前端自动归位默认档「近无损 4:4:4 CRF14」，后台也接受旧空值并回退，不再报 `Value not in list: 母版画质` 校验错误。
- 本版含后台改动：保存工作流、结束当前任务后重启 ComfyUI，再 Ctrl+F5。

## 三个核心节点

1. **AD-素材准备**：图片、视频、音频批量导入；多轨时间线拖动、裁剪、切断、拼接与合并；支持按小节、每拍、镜头或气口智能切分。
2. **AD-分段生成**：按素材时长组织分段，24 FPS 严格锁帧，适配 H3 的 17k+5 生成帧数；逐段控制宽高、提示词与参考素材。
3. **AD-分段预览**：逐段播放、A/B 对比、指定段抽卡、停止续跑、连续分段循环与片段合并。

搭配 **AD-最终保存**，可对所选成果执行外部加工、批量保存和合并；v0.5.17 起可在节点内选择母版画质（默认 4:4:4 / CRF14）并用「下载母版」保存源画质成片。先在分段预览中选择成果，再点击「加工所选」。停止后可点击「继续剩余」。

## 主要功能

- **多素材导入**：统一管理图片、视频、音频，支持批量加载与拖放导入。
- **剪映式多轨编辑**：视频、音频各 3 轨；支持多选整体移动、同类换轨、独立首尾裁剪、切断、合并与撤销/重做。
- **灵活分段**：按时长、段数或智能切点组织片段；无素材时可按正向提示词中行首 `#` 自动建立分段。
- **智能切分辅助**：音频踩节拍、小节切分、视频镜头检测与人声气口检测。
- **多音源处理**：多路音频独立裁剪、切分与静音，短段按需要补静音。
- **参考素材独立输出**：参考图片、参考视频帧、视频音轨与音频轨素材按端口输出。参考视频、视频音轨和时间线遮罩按 24 FPS 帧位对齐，段尾余量从当前段补齐。删除片段时同类轨道自动前移，已连接的参考线固定在原端口不动；全部素材清空后已有连线仍保留。
- **原始素材直出**：源视频、源音频与分段参考输出分开使用，便于连接现有工作流。
- **清晰预览与对比**：图片、视频、音频分类预览，支持缩放、全屏与 A/B 对比；视频 A/B 为叠加重合擦除（分界线跟随鼠标，支持同步帧、帧率比对齐与坏文件提示），图片 A/B 默认左右、可切叠加滑杆。
- **自由抽卡与续跑**：指定段重新生成，保留历史成果；支持停止待命、断点续跑与连续分段循环。
- **逐段采用最新设置**：下一次提交读取当前素材、连线与生成设置，已完成成果保留。
- **独立任务与历史组**：工作流任务隔离。清空重置会归档已有结果，可在记录完整时恢复历史组续跑。最近 10 轮可回抽，沿用该轮的分段和潜桥链，使用当前编辑的提示词、参考和采样设置。
- **批量保存与循环复用**：素材与结果可继续作为输入，配合最终保存节点完成批量输出和合并；母版画质可选 4:4:4/CRF12–16，下载母版不会保存预览代理。
- **接缝处理与进度管理**：提供接缝治理、进度保存、素材占用提示及缓存清理；素材占用默认上限 30 GB，可用环境变量 AIDEN_H3_MEDIA_LIMIT_GB 调整。

## 潜桥续接

在「AD-分段生成」中将「潜桥续接」设为 5、22 或 39 帧即可开启，设为 0 可关闭。插件内置潜桥运行时，提交时自动连接桥接、存盘和裁头。请将分段上下文与对应的 `CreateVideo` 输出接到「AD-分段预览」。

启用后，输出段长按 17 帧对齐，生成时加入上下文帧，输出时裁掉这部分画面和生成音频。原本按段截取的源音频继续使用本段范围。自动重排适用于连续、同源的单条视频轨，独立音频轨和不连续片段保留原有剪辑。

「重锚定」按选定的段间隔读取该轮第 1 段的 latent，也适用于历史轮回抽。「色彩匹配」可以按参考视频进入本段后的首个素材帧做整段校色。

## 安装与使用

1. 从 [最新发布](https://github.com/tibidefengzi/ComfyUI-AD-Segmented-Loop/releases/latest) 下载插件 ZIP，解压后将插件目录放入 `ComfyUI/custom_nodes/AD-Segmented-Loop`。保持只有一份启用的插件。
2. 用运行 ComfyUI 的 Python 安装依赖：
   ```bash
   python -m pip install -r custom_nodes/AD-Segmented-Loop/requirements.txt
   ```
3. 保存工作流、等待当前任务结束后重启 ComfyUI，再按 `Ctrl+F5` 刷新页面。节点位于 **AD-Segmented-Loop** 分类。

H3 的模型、条件编码、采样器与生成链路在外部工作流中连接；模型及第三方二进制不包含在安装包中。
